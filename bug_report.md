# Bug Report

## Issue: Button Text Capitalization

**Description:**
The text "Vfood" within the main landing page buttons is incorrectly being displayed in all uppercase, despite multiple attempts to correct it with CSS. The desired behavior is for "Vfood" to be displayed with its proper capitalization ("Vfood").

**Details:**
- The issue is present on the main landing page (`index.html`).
- The buttons are styled with the `.button` class in `style.css`.
- The `.button` class has a `text-transform: uppercase;` rule.
- Attempts to override this rule with more specific selectors have been unsuccessful.

**Next Steps:**
- This issue needs to be resolved before the production delivery of the website.
